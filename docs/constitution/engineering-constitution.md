# Engineering Constitution

## Status

Accepted foundation artifact.

## Authority

This constitution derives from `MASTER_PROMPT.md`. If this document and the master prompt conflict, the master prompt wins unless explicitly changed through the governance process.

## Immutable principles

1. Correctness before optimization.
2. Requirements before architecture.
3. Architecture before technology.
4. Technology before implementation.
5. Business logic must not depend on infrastructure.
6. Everything measurable.
7. Everything traceable.
8. Everything reviewable.
9. One source of truth.
10. Prefer simplicity over unnecessary complexity.
11. Prefer eliminating work over optimizing work.
12. Green Computing is a first-class quality attribute.
13. Every dependency must justify its existence.

## Engineering order

Work must flow through these stages unless a documented exception is approved:

1. Idea
2. Vision
3. Requirements
4. Architecture
5. Specifications
6. Implementation plan
7. Implementation
8. Verification
9. Deployment
10. Operations
11. Evolution

## Required classification

Every non-trivial engineering artifact must distinguish facts, requirements, assumptions, constraints, recommendations, risks, and tradeoffs.
